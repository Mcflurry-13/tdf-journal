<Entry date="TBD" title="Input · Knob Control">

I used a potentiometer to control the servo, mapping the A0 reading to an angle on D9. Adding serial output helped me separate input problems from motor problems: I could check the knob value and the commanded angle together.

These experiments build on the [class Arduino tutorial](https://github.com/loopstick/ArduinoTutorial#servo-motors).

<Entry date="TBD" title="Motion · Sweep and Position">

I tested automatic movement with the Sweep example. On the physical MG90S, I encountered continuous rotation during the wider-range tests. I then isolated the motor and confirmed that it could move to and stop at 60°, 90° and 120°. This became the smaller range for the sensor experiment.

<Entry date="TBD" title="Interaction · Distance to Motion">

I combined the ultrasonic sensor with the servo, moving from a distance threshold to a continuous angle mapping. The sensor uses TRIG on D7 and ECHO on D6; the servo stays on D9, with a shared ground.

The 5–200 cm mapping made small hand movements barely visible. The latest code narrows the input to 10–30 cm and the output to 120–60°, changes the command by at most 2° per cycle, and holds its position when no echo is received. Serial values show commands, not measured motor angles.
