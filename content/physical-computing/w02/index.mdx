<Entry date="TBD" title="Input · Knob Control">

When the servo did not respond as expected, I needed to know whether the problem came from the knob or the motor. I printed the potentiometer reading and target angle together. Comparing those values with the physical movement helped me check the input and mapping separately from the servo itself.

These experiments build on the [class Arduino tutorial](https://github.com/loopstick/ArduinoTutorial#servo-motors).

<Entry date="TBD" title="Motion · Sweep and Position">

The wider-range tests sometimes made the MG90S keep rotating, so I tested the motor on its own before adding the sensor back. I sent fixed commands at 60°, 90° and 120° and checked whether it stopped at each position. Those tests worked, so I used that smaller range for the next experiment.

<Entry date="TBD" title="Interaction · Distance to Motion">

The distance readings changed as I moved my hand, but the servo barely moved. Checking the Serial Monitor showed why: mapping 5–200 cm across only 60° gave small hand movements almost the same target angle. I narrowed the input to 10–30 cm and limited movement to 2° per cycle, then compared distance, target and command values to check the response.
